# Issue #1064: copy-paste snippets for llm agents

Source: https://github.com/jepegit/cellpy/issues/1064

## Original issue text

Let us update the docs to contain snippets the user can copy-paste and provide it to their LLM agent.

For example:

How to install cellpy MCP

"Install the cellpy MCP server, register it with Cursor, and run cellpy mcp check --client cursor to prove it works. Follow https://cellpy.readthedocs.io/en/latest/getting_started/mcp/."

Suggest about 10 snippets that we believe will be helpful for the users. It might be that we shold implement some kind of tracking of hard links and comments (like the link https://cellpy.readthedocs.io/en/latest/getting_started/mcp/ in the example above) so that it is easy to update the docs when cellpy or its docs change.
