# Close step 6 — sync with the default branch

The issue branch must carry whatever landed on `<default>` while this issue was in flight; otherwise the PR only fails later as `mergeable: CONFLICTING`. A plain `git pull --ff-only` on the issue branch cannot do this.

- **CLI fast path (preferred).** `issue-flow agent sync-branch --json` refuses while the tree is dirty or you are on the default branch, fetches, replays the branch onto `origin/<default>`, and **auto-resolves bookkeeping conflicts** keep-both: additive bullets under `## [Unreleased]` in `HISTORY.md` (already-landed bullets first, the in-flight issue's last), and additive bullets / table rows in `.issueflows/04-designs-and-guides/*.md` or any `issue<N>_status.md`. The payload's `resolvers` map says which file got which resolver. Any other conflict (product code, an edited existing line, a heading or prose collision) aborts the rebase, leaves the branch as it was, and exits 1: report its `notes` and **stop**. When the payload reports `needs_force_push: true`, push with `--force-with-lease`.
- **Stacked on a squash-landed parent.** When this branch was cut from another issue branch that has since been squash-merged, a plain rebase replays the parent's commits too. `sync-branch` detects that (payload `base_detected: true`, `base: <parent>`, `dropped_commits: <n>`; the parent must be provably landed) and replays only the commits after the parent via `git rebase --onto`. Pass `--base <ref>` when you know the parent and detection did not fire (the ref must be an ancestor of `HEAD`).
- **Manual fallback.** `git fetch --prune`, then `git rebase origin/<default>` (or `git rebase --onto origin/<default> <parent-tip>` for a stacked child). Keep both sides only for additive bullets / table rows in `HISTORY.md`, `04-designs-and-guides/*.md`, and `issue<N>_status.md`; `git add` and `git rebase --continue`. For anything else, `git rebase --abort` and **stop**.
- Never rebase, force-push, or rewrite the **default** branch. Rewriting the issue branch (`--force-with-lease`) is the normal outcome of this step.
