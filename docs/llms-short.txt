# cellpy

> Python library + `cellpy` CLI for battery cycling data. Not a hosted GUI.

- Entry: `import cellpy` then `c = cellpy.get(path, mass=..., instrument=...)`
- Frames: `c.data.raw` / `.steps` / `.summary`; columns via `c.schema`
- Batch is the multi-cell journal API; MCP is a chat client over `cellpy-mcp`; this file is the library-import path
