# Skills for cellpy users

These skills teach an agent how to analyze battery cycling data with cellpy.
They are for researchers using cellpy, not for people changing the cellpy
source.

Do not copy this folder into `.cursor/skills/`. Skills there load while
developing cellpy. A user installs a skill into their own agent by copying
`skills/<name>/` into that agent's skills directory.

Each skill is one directory with a `SKILL.md`, matching the Agent Skills
layout used by skills collections (`skills/<name>/SKILL.md`).
